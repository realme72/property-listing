# Java starter

This project uses Java 25 and Maven.

## Requirements

- JDK 25
- Maven 3.9 or later

Check your installation with `java -version` and `mvn -version`.

## Build, test, and run

```sh
mvn test
mvn package
java -cp target/classes com.example.App
```

The VS Code extension recommendations include the Java language support and
Maven extensions. Open this folder in VS Code and install the recommendations
when prompted.
